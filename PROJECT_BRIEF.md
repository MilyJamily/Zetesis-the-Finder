# Zetesis the Finder

## What is it?

Zetesis the Finder is an open-source project that provides an immersive,
visual, and adaptable investigation and research experience to satisfy users' curiosity.

## Who is it for?

It is for people who enjoy doing research, exploring information, and
discovering new things.

## What is the main type of information?

Public figures.

## What is the default result?

- Name
- Image
- Description
- Basic information
- Sources

## What will be the first visualization?

A digital investigation profile card containing the person's image,
basic information, description, and sources.

## What will not be included in the first version?

- The "Add Info" feature
- Connection graphs
- User accounts
- Multiple information categories
- Advanced animations and 3D effects

## Safety and privacy rules

- The project will use publicly available information.
- It will not display private or sensitive personal information.
- Every important piece of information should have a reliable source.
- Unverified claims will not be presented as facts.
- The project will not be used to harass, track, or expose private individuals.

## How will we know that the first version works?

The first version works when a user can search for a public figure and see
their name, image, basic information, description, and reliable sources in
the investigation profile card.
